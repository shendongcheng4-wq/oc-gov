# 工作台演示视频 · 分镜单（现场用 · 对应当前成片 5:15）

> 一页一段，录的时候只看这张表。字幕按段内时间码压，段与段拼接顺序就是编号顺序。
> 成片规格：1920×920 / 30fps / h264 / AAC 48k；字幕 50px 雅黑粗体，底距 42px。


## 录制前设定

| 项 | 要求 |
| --- | --- |
| 窗口 | 浏览器 1920×920，贴左上角，缩放 100%，隐藏书签栏 |
| 登录 | 口令统一 `ocgov2026`；换身份必须先退出再登录 |
| 模型 | 8099 单独起好，全程别关（06、07、13 都靠它） |
| 参谋 | 06 之前先选「经济运行参谋」，不选就没有解读卡 |
| 会议快照 | 08 之前跑 `python tools/demo_snapshot.py snap`，落了库可 `back` |
| 抽奖项 | 06 的「删了 1 句」不是每轮都有，先跑一遍再决定拍不拍 |
| 数据 | 打开罗盘记下当天真实数字，字幕里的数按屏幕填 |


## 字幕规范

- 一条一屏，单行 ≤18 字；两行一屏的只有 06 段那一问。
- 语速 4—6 字每秒，数字句可到 7；全片 120 条 / 1256 字。
- 出现比动作晚 0.3 秒，退场淡出 0.2 秒；品牌蓝 `#1A63C9` 12% 透明底、白字 50px 雅黑粗体。
