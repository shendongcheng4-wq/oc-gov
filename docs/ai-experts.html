可召唤的四位参谋

在对话框里打一个 / 就能点将。参谋只负责补一段「怎么看」， 不负责报数 —— 因为数字只能有一个来源。

  • 4可召唤角色
  • 3一次最多同时
  • 1数字唯一来源

01名单

三位常设参谋，外加把三位一次叫齐的「参谋团」。差别是关注面，不是取数逻辑 —— 同一份数字，看的角度不同。

三个容易踩的地方

这些不是细节洁癖，是「不处理就没法用」的问题：

  • 只在行首认。「投资/工业」「环比/同比」是问句里的正常写法，只要含斜杠就弹菜单，问题根本打不完。
  • 全角 ／ 也认。中文输入法按 / 上屏的常常是全角字符，只认半角等于让一半人打不出来。
  • 组词中的 Enter 不抢。中文选词也是 Enter，抢了就是一打中文就误选人。
  • 继续打字是过滤：/经 只剩经济参谋，/eco 按 id 也能命中。
  • 再选一次已在对话中的那位，就是取消 —— 空着代表没人插话。

03为什么参谋不许报数

若让专家自己去查数，同一场会里经济参谋说 8.9%、民生参谋说 9.1%，谁也说不清该信谁。

所以数字只能有一个来源：指标接口。参谋在这之后再补「怎么看」。
  1. 数字闸：出现数字，整段丢弃

    解读里一旦出现阿拉伯数字或百分号，整段作废并注明原因，不做「修正」—— 数字只要出现过，就没法判断它是不是编的。唯一例外是指标名自带的数字（如「12345 群众诉求按期办结率」），校验前先剔掉。

  2. 连素材也不给数字

    传给参谋的只有指标名称和方向信号（「同比上升」「环比下降」，由代码从原始值折算）。想报数也没有素材。

  3. 一次最多三位

    这是并发成本上限：一位参谋 = 一次模型调用、一份 token。名单可以扩，但一次会诊不该变成刷模型。

  4. 模型不可用时不让问答失败

    参谋段标注「未配置模型」，数值答案照常返回。降级的是解读，不是答案。

  5. 解读不进下一轮上下文

    回灌给模型的上一轮摘要只保留指标名和意图，不含任何数值 —— 模型在上下文里看见数字，下一轮就更可能复述甚至改动它。

04它不做什么

边界写清楚，比能力写满更有用。

不改任何数据

参谋只读指标、只出文字。写完的东西要落库，必须走人确认的流程。

不替人下判断

给的是角度和风险提示，不是「建议怎么办」。决策留在会上。

不碰顶栏工具

会议助手、督办、日程、材料、提醒是页面导航，不在 / 里 —— 免得让人以为能在对话里指挥它们。
