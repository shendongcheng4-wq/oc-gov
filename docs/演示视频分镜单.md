# 工作台演示视频 · 分镜单（录制现场用 · 无声字幕版）

> 配合 `演示视频脚本_v2.md` 使用。脚本是给人读的，这张表是给手和字幕用的。
> **全片不出人声**，信息全靠画面 + 字幕承载。

## 怎么用

1. 印出来，或者放第二块屏。只盯当前行和下一行，别试图记全片。
2. **只做"手"这一列**，录制时不用管字幕——字幕是后期加，你只要把动作做干净、节奏留够。
3. **每步做完停 1 秒再动下一步**。没有旁白压节奏，画面全靠停顿时长。
4. 字幕列里的 `‖` 是**断条分界**：一条字幕一屏只出一句，别连成一长串。

## 录制前设定（这几条不照做，后面全白干）

| 项 | 值 | 说明 |
| --- | --- | --- |
| 窗口 | **1920 宽 × 920 高**，贴屏幕左上角 | 底部空出的 160px 是字幕带。窗口占满全屏就没地方放字幕了 |
| 屏幕分辨率 | 1920×1080 | 录全屏，窗口 1920×920，多出来的底部区域后期裁掉 |
| 音频 | **不录**（关麦） | 无声片，省得后期对轨 |
| 缩放/书签栏 | 100%，隐藏书签栏和任务栏 | 缩放一变，四张卡就挤成三张 |
| 参谋 | ③ 第一问之前，先选「经济运行参谋」 | 不选人，答案下面就没有解读卡，3-5 / 3-6 全落空 |
| 预热 | 带参谋把第一问跑一遍，**看有没有"删去了 1 句…"那行小字** | 那行不是每轮都有，先跑一遍才知道 3-6 拍不拍得到 |
| 会议快照 | 录之前跑一次 `python tools/demo_snapshot.py snap` | 4-5 点「落督办」是一次性写入，落了就回不去；**NG 一次这段就废** |
| 会议数据 | 确认 `MT2026-0002` 是 **2 条事项、0 条已落** | 已经落过库，4-5 的勾选框就没了，整段拍不成 |
| 通知回执 | 确认 `MT2026-0003` 是 **会期 12-03、已发通知 0 版** | 发过一次就变成"已发 1 版、已读 0/5"，4-8 再发只会提示"今天已发过同一版"，发不出去 |
| 材料助手 | 模型开着，先点一次「重新生成」，**确认工具栏标签是绿色** | 模型挂了会悄悄退回规则文本，标签变黄"按台账事实生成"，"AI 写的"就没了 |
| 知识库 | 确认搜「入河排污口」能出 5 条、跨 4 类 | 这是唯一能同时带出政策、会议、督办、议定的词，换词就只剩一半 |

> **为什么是 920 而不是 1080**：字幕烧在画面底部，而罗盘页左下的"统筹推进"分档按钮正好在画面最下沿——2-3 就要点它。字幕一盖，观众看不到你在点哪个档。把窗口压到 920，字幕落在页面下方的空白里，永不遮挡。
>
> **录完先看一眼画面底部有没有滚动条**。有，说明高度不够，把窗口拉到 900 再来一遍。
>
> **佐证素材**在桌面「演示佐证」文件夹，两个文件（见 5-4）。录制前先各双击打开看一遍：一是确认能正常显示，二是 Windows 有了预览之后，文件对话框里才出缩略图，现场找得快。**看完就关，不要在系统里试传。**

## 字幕规范（后期照这条做，或者交给我）

| 项 | 值 |
| --- | --- |
| 画布 | 1920×1080（内容区 1920×920 在上，字幕带 160px 在下） |
| 字幕带 | 深蓝底 `#0f2744`，与页面横幅同色系，看着是一体的 |
| 字号 | 42—46px，微软雅黑 / 思源黑体，白色 |
| 每条字数 | **≤ 18 字**，一行排完；超了就断条，不要挤成两行 |
| 每条停留 | 2—4 秒。13 字以内给 2 秒，18 字给 3.5—4 秒 |
| 出现时机 | **比动作晚 0.3 秒**。先让观众看见画面变了，再出字 |
| 退场 | 每条**淡出 0.2 秒**，不要硬切 |

> 没有配音，字幕就是唯一的信息通道。**宁可少说一句，也别让字挤成两行**——两行字幕在会议室投影上根本读不完。

## 分轨录制（重要）

不要一条录到底。按下面四轨分别录，剪辑时拼起来——**换身份的等待就不占正片时长了**：

| 轨 | 内容 | 起止身份 |
| --- | --- | --- |
| A | ①②③④⑤（开场 → 罗盘 → 问政 → 会议 → 督办） | 市长，一口气录完 |
| B | ⑥（单位视角） | 从登录页开始，录到退出 |
| C | ⑦（交办到人） | 市长 → 秘书，两次登录都在轨内，整段剪掉 |
| D | ⑧⑨（写材料、收尾） | 任意身份；⑧ 用市长，⑨ 回罗盘整屏 |

A 轨最长（约 4 分 30），中间有两处要等：③ 第一问约 11 秒、第二问约 20 秒。**等的时候手离开鼠标、别切窗口**，答案出来再多录 3 秒。

> A 轨里 ④ 和 ⑤ 之间**不要剪断**：④ 最后落进去的那条，⑤ 开头就要在台账里点开它，接得上才叫闭环。两段在素材里连着录，中间别停。

| --- | --- | --- | --- |
| 2-1 | 0:15–0:23 | 鼠标从顶部横幅慢慢划过，停在第一张 KPI 卡上，**不点** | 打开就是这一屏 ‖ 上面一排是本期关键指标 ‖ 每张卡都带同比和期次 |

| 2-4 | 0:51–1:02 | **点第一张卡**（地区生产总值），抽屉从右侧滑出；若"数据来源"没露出来，用滚轮往下带一格，停 3 秒 | 点开任意一张卡 ‖ 出来的是它的口径和出处 ‖ 怎么算的、谁给的 ‖ 出自哪份报表、哪天披露 |
| 2-5 | 1:02–1:05 | 抽屉保持打开，鼠标不动 | 大屏给你数，这里告诉你数从哪来 |
| 2-6 | 1:05–1:12 | 关掉抽屉（右侧 ✕），鼠标移到**右下角**「焦点推送 · 民情焦点」卡上，沿三条焦点从上往下扫一遍 | 右下这块不是指标 ‖ 是老百姓反映的事 ‖ 四个渠道聚成几条焦点 |
| 2-7 | 1:12–1:23 | 点卡片底部「查看全部焦点 →」，弹窗打开（默认选中第一条）；鼠标停在**左侧列表第一条那行**"96 人反馈 · 受理 128 件"上，慢慢描一遍 | 受理 128 件，96 个人 ‖ 这两个数，不是一个口径 |
| 2-8 | 1:23–1:33 | 移到右栏「多少人反馈 96 人」，停 3 秒在下行小字"按联系人去重：一人多次来电只计 1 人，和上面的工单件数不是同一个口径"上 → 再轻轻扫到弹窗**最底部那行口径注解**（四渠道聚类、不含真实个人信息、转办以 12345 工单为准）；**手停住，别关弹窗** | 一人打十次电话，只算一个人 ‖ 它没揉成一个好看的数 ‖ 还有一条：一件工单，涉 37 人 |

> **2-1 那张卡不要点。** 一点，右侧 432px 的抽屉和半透明遮罩就出来了：整屏变暗，左下"统筹推进"被遮罩挡住，2-3 还得先关抽屉再点分档——多两个动作，画面还明暗闪两次。**点抽屉是 2-4 的活，全片只点一次。**
> **2-2 是这一段最值钱的地方**：并排两张卡的期次就不一样（2025 年全年 / 今年 10 月）。不用讲"期次很重要"这种道理，手一指，观众自己看见。鼠标要**先停第一张卡底部那行小字**，再移到第二张。
> **2-4 点第一张（GDP），不要点第二张（工业增速）**：第二张是 10 月当月 8.6%，而 ③ 段问数答的是 1—9 月 8.9%，同一个指标两个数隔一分钟先后出现，评委会当场问哪个对。点第一张正好避开；而且第一张的抽屉里有一句"演示用的月度曲线与它不是同一期、也不是同一口径，已隐藏"——全片最反吹牛的一处，值得让画面停住。
> 2-3 的六档分档名不上字幕：画面上写着，观众看得见。字幕只讲"点哪个分档筛哪几条"。
> 2-1 的"划过"要慢，2 秒划到底——一甩就过去了，看着像在找东西。
> **2-6～2-8 是"数"的另一半：指标是部门报上来的，焦点是老百姓说出来的。** 前面 2-4 讲的口径是"这个数怎么算的"，这里讲的是**"件数和人数根本不是一个东西"**——一件工单可能牵扯几个人，一个人打十次电话只算一个人。同一件事讲两遍不算啰嗦，因为它就是这个系统的脾气：**每个数都得说清是怎么数的**。
> **别把它讲成"舆情监控"。** 它不抓人、不做情感分析、不对人打标签。弹窗底部那行写着"演示数据不含真实个人信息，转办与办理状态以 12345 平台工单为准"——2-8 收尾时手可以轻扫过那一行，但别念成一句承诺。
> **2-7 点卡片底部的「查看全部焦点 →」，不要点某一条。** 点单条也进同一个弹窗，但点"全部"更像"我要看全"；而且默认就选中第一条（96 人 / 128 件），省一次点击。
> **2-8 手要停在右栏那行小字上**："按联系人去重：一人多次来电只计 1 人，和上面的工单件数不是同一个口径。" 这是整段的落点——**它没把两个数揉成一个好看的数**。
> 2-8 最后一条字幕"一件工单，涉 37 人"，说的是左侧列表第三条（某企业欠薪线索涉 37 人）—— **它就在画面里**，不用去指，但**镜头要带到左侧整列**，否则观众不知道你在说哪一条。

> **3-1 不选参谋，3-5 和 3-6 就没东西可拍。** 这是参谋功能唯一的入镜方式：问数面板里选人，答案下面才出解读卡。
> **画面从上到下是：数 → 参谋卡 → 处理过程。** 鼠标一路往下走，别往回跳——往下走观众跟着看，跳来跳去就散了。
> **3-2 必须逐字打，不能粘贴**——粘贴没有输入过程，画面会突然多出一行字。
> **3-3 那 5 秒一个字都不出**，圆点在呼吸就是它真的在算。
> **3-6 看运气。** "删去了 1 句含无法溯源数字的话"这行不是每轮都出现，取决于模型这轮有没有编。**录之前先跑一遍看有没有**：有就照拍，没有就把这 11 秒还给 3-5，字幕只留"往下是参谋的解读"那几条。
> **3-9 的 20 秒必须等满**，手离开鼠标，别切窗口，答案出来再录 3 秒。正片剪到 2—3 秒（见脚本第九节）。
> 3-5 字幕说的是"**建议**谁去核"，不是"派了任务"——参谋给的是建议，落不落地是人的事，别说成系统自动派单。
> 3-10 三个数字要**依次**指到，别一口气乱划——观众是跟着鼠标看数的。

## 字幕密度

每段的条数、平均停留、最密的那一镜，**不在这张表里写死**——`docs/分镜图/00-速查.png` 每次生成时现算，
