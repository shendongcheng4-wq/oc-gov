# 字幕改稿 · 第三人称叙述 + 市长 / 秘书双角色

> 只改文案，不碰画面。SRT 在同目录 `srt/` 下，编号即拼接顺序，文件名后是段名；逐段对应哪条源片，见第三节每段开头那行「源片」。

> 全片 14 段 / 315 秒 / 120 条字幕 / 1256 字，平均 4.0 字每秒。


## 一、这一稿改了什么

**1. 讲解改成使用说明：先说目的，再说操作。** 原来每段讲的是「看到了什么」，现在每段回答一个问题——「想弄清一个数怎么来的，就点开这张卡」「要催件，进督办台账」「办完才发现材料不全，怎么办」。听完能照着做，而不只是听懂我们在夸它。

**2. 开场先教认这一屏。** 一屏四块：上面四张关键指标、中间六个板块（经济运行 / 招商引资 / 重大项目 / 社会治理 / 民生保障 / 焦点推送）、左下统筹推进、右边智能问数。先把地图交出去，后面每段都能指位置——「要盯进度，看左下统筹推进」「右边智能问数，先挑一位参谋」。

**3. 判断句改成操作提示。** 「期次不一样，别一起比」→「比数之前，先对齐期次」；「只能勾绿的」→「绿的字段齐，能直接落 / 橙的缺时限，得先补 / 所以只勾绿的」；「缺一样，就不让下发」→「原文没写清的，它先列出来」。结论变动作，观众才知道下一步点哪。

**4. 两个角色保留，改成「谁用哪块」。** 逐段抽帧核对了 14 段右上角的身份徽标，实际是：

| 身份 | 有哪几段 | 用哪一块 |
| --- | --- | --- |
| 市长 | 01 开场、02 罗盘指标、03 统筹推进、04 口径、06 问政、07 处理过程、10 补挂、14 模型 | 罗盘看数、智能问数问数、交办派活、后台换模型 |
| 市长秘书 | 05 民情焦点、08 会议、09 督办、13 写材料 | 民情焦点、会议助手发通知、督办台账催办、材料助手起稿 |
| 市城管局 | 11 单位视角 | 工作台：只填本单位进度、传佐证 |
| 市长 → 秘书 | 12 交办 | 一句话派下去，落到秘书日程 |

旧稿不是没讲角色，是**一次都没交代**：徽标从「市」跳到「秘」再跳回来，观众只看见它在变。这一版每次换账号都在段首点名（「换成秘书账号，就能看到」「换单位账号，用法不一样」），12 段那两次切换因此成了全片的教学主线。

**5. 顺手改掉八处与画面对不上的地方**（详见第五节）。
